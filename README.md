# Sistema de Gestão Escolar

Sistema desenvolvido em Portugol (VisualG) para praticar lógica de programação, algoritmos e resolução de problemas por meio da simulação de um sistema de gerenciamento escolar.

## Funcionalidades

- Cadastro e gerenciamento de alunos
- Correção automática de provas utilizando gabaritos
- Registro de frequência
- Cálculo de médias e geração de boletins
- Consultas e relatórios da turma

## Tecnologias

- Portugol (VisualG)

## Objetivos do projeto

- Praticar lógica de programação
- Desenvolver algoritmos utilizando modularização
- Aplicar estruturas condicionais e de repetição
- Trabalhar com vetores e funções
- Consolidar conceitos fundamentais para o desenvolvimento de software
